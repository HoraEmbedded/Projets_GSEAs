# Mobile Robot Path Following via Artificial Vision

## Project Overview
This project aims to design and simulate a complete path-following system for a differential mobile robot using artificial vision. The entire simulation is developed in MATLAB/Simulink without relying on physical hardware.

## Directory Structure
* `src/`: MATLAB source code (image processing, map generation).
* `models/`: Simulink models (`.slx` files).
* `scripts/`: Initialization and post-processing scripts.
* `docs/`: Technical reports, specifications, and presentations.

## Environment
* MATLAB/Simulink R2024b
